# 윷놀이터 — 온라인 윷놀이 MVP

Node.js, TypeScript, React/Vite와 Socket.IO로 만든 로컬 실행용 실시간 윷놀이입니다. 서버가 방·턴·말 위치·윷 결과를 관리하는 권위형 구조라 서로 다른 PC와 휴대폰도 같은 게임 상태를 공유합니다.

## 포함 기능

- 최대 8명, 개인전/팀전 방 생성과 5자리 코드 입장
- 게임 중에도 최대 50명 관전 입장(참가 인원 8명과 별도, 실시간 화면·채팅만 가능)
- 대기실에서는 플레이어와 관전자 역할을 자유롭게 전환 가능(게임 시작 뒤 역할 고정)
- Socket.IO 실시간 상태 동기화와 채팅
- 도·개·걸·윷·모·빽도·낙, 윷/모 및 잡기 추가 턴
- 4개 말, 업기, 잡기, 지름길, 완주 판정
- 브라우저 새로고침 시 같은 방으로 자동 재접속 시도
- 반응형 PC/모바일 화면 및 서버 결과를 재현하는 Three.js 윷 굴림 모션
- 방 코드·초대 링크 입장, 대기실 링크 공유, 팀 직접 선택 및 랜덤 팀 섞기

## 윷 결과 확률

현재 MVP의 서버 난수 비율은 도 22%, 개 28%, 걸 21%, 윷 10%, 모 8%, 빽도 6%, 낙 5%입니다. 추가 던지기와 역전 상황을 조금 더 자주 볼 수 있도록 조정한 재미 우선 설정입니다. 방 설정으로 조절하는 기능은 다음 단계에서 추가할 수 있습니다.

## 설치와 실행

Node.js 20 이상을 설치한 뒤 프로젝트 폴더에서 실행합니다.

```bash
npm install
npm run dev
```

PC에서는 `http://localhost:5173`을 여세요. 같은 Wi-Fi의 휴대폰에서는 PC의 로컬 IP를 사용합니다. 예: `http://192.168.0.10:5173`. Windows 방화벽에서 Node.js 접근을 허용해야 할 수 있습니다.

## Render 배포

이 프로젝트는 `render.yaml`을 포함하고 있어 하나의 Render Web Service로 배포할 수 있습니다. GitHub에 이 프로젝트를 올린 뒤 Render에서 **New → Blueprint**를 선택해 저장소를 연결하세요. Render가 `render.yaml`을 읽어 빌드(`npm ci && npm run build`)와 실행(`npm start`)을 자동 설정합니다. 배포가 끝나면 생성된 `https://...onrender.com` 주소를 모든 PC·휴대폰에서 사용하면 됩니다.

Render 웹 서비스는 외부 WebSocket 연결을 지원하며, 이 프로젝트는 HTTPS 주소에서 Socket.IO를 같은 도메인으로 연결합니다. 무료 인스턴스는 일정 시간 사용하지 않으면 첫 접속이 느려질 수 있으므로, 실제 게임 운영에는 상시 실행 플랜을 권장합니다.

## 테스트와 확인 절차

```bash
npm test
npm run build
```

1. 브라우저 창 두 개(또는 PC와 휴대폰)를 엽니다.
2. 첫 창에서 방을 만들고 대기실의 **초대 링크 공유**를 누릅니다.
3. 다른 창에서 링크를 열거나, 코드/링크를 입장 카드에 붙여넣습니다.
4. 팀전이라면 각자 팀을 고른 뒤, 방장이 게임을 시작합니다.
5. 차례인 플레이어가 윷을 던지고 빛나는 목적지 칸을 눌러 이동합니다.
6. 상대 말에 도착하면 상대 말이 출발로 돌아가고, 윷/모/잡기 후에는 다시 던질 수 있는지 확인합니다.
7. 새로고침 뒤 방 상태가 다시 표시되는지 확인합니다.

## MVP의 규칙 범위

지름길은 모서리 및 중앙 선택 칸에서 플레이어가 직접 고를 수 있습니다. 판 위에 내 말이 하나도 없을 때 나온 빽도는 무효로 차례가 넘어가며, 빽도는 출발 대기 말에 적용할 수 없고 언제나 정확히 한 칸 뒤로 이동합니다. 출발·완주 칸에 정확히 도착하면 그 칸에 머물고 다음 이동에 완주하며, 그 칸에 닿은 뒤 이동력이 남아 있으면 같은 이동으로 완주합니다. 팀전은 같은 팀 색상 플레이어들의 완주 수를 합산해 승리합니다. 윷 애니메이션은 Three.js로 재현하지만, 결과는 항상 서버가 먼저 확정하므로 모든 기기에서 같은 결과를 봅니다.
